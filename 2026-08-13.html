内核 / 进程与格式

用 BPF 为 binfmt_misc 带来解释器选择

作者：Jonathan Corbet 发布日期：2026年8月6日 英文原文

Linux 内核原生支持 ELF 等可执行格式，并通过 binfmt_misc（自 1997 年的 2.1.43pre1 引入）让用户空间配置对"任意格式程序"的透明执行。配置通过向 /proc/sys/fs/binfmt_misc/register 写入完成，可基于文件头 256 字节的模式或扩展名匹配，例如 :DEXE:M::\x0eDEX::/usr/bin/dosexec: 或 :python:E::py::/usr/bin/python3:。条目按与注册顺序相反的次序被检查。

Hermetic 二进制带来的难题

Nix 等发行版需要可重定位（hermetic）的二进制，但 ELF 的 PT_INTERP 字段要求用绝对路径指定动态链接器。Farid Zakaria 提议允许相对路径，却遭到 Kees Cook 与 Christian Brauner 反对——Brauner 称这容易引发"恶意加载器注入攻击（malicious loader injection attacks）"，转而建议扩展 binfmt_misc，用 BPF 程序来选择一个解释器。

BPF 接管 binfmt_misc

Brauner 发布了补丁，提供 struct binfmt_misc_ops，包含 match()、load() 回调以及 name 字段。match() 可以读取整个可执行文件（而非仅限于 256 字节）；load() 则通过 bpf_binprm_set_interp() 设置解释器。注册字符串形如 :name:B::::bpf-handler-name:。Zakaria 确认该方案满足 Nix 的用例，并且能让 #! 行的解释器也可重定位。

进一步的步骤

  • 透明分发（transparent dispatch）模式（T 标志）：内核直接执行该二进制，但在幕后替换解释器；argv 与命令字符串保持原样，解释器通过 AT_EXECFD 拿到该文件的文件描述符。
  • 加载器替换（loader substitution）模式（L 标志）：仅覆盖 PT_INTERP，适用于原生二进制。
  • 预打开解释器的问题：BPF 可以任意设定路径，但在命名空间内可能被劫持。Brauner 的补丁允许在注册时预先打开一组解释器，并新增"disabled"模式（例如先 echo ':qemu:B::::qemu_user:D' > register，再逐行追加）。
  • 资源限制：限制每用户可保持打开的解释器文件数量，以防用户命名空间耗尽资源。

状态：除资源限制系列外，其余均已进入 linux-next，预计在 7.3 合并窗口进入主线。

嵌入式 / 固件

CrossPoint 电子书阅读器固件一览

作者：Joe Brockmeier 发布日期：2026年8月12日 英文原文

Xteink 等厂商出口袋电子书阅读器（例如 Xteink 4，采用 ESP32 芯片、4.3 寸屏、无触控）。CrossPoint 项目（MIT 许可，200+ 贡献者）提供替代固件，支持 6 款 ESP32-C3/S3 设备，售价 50–80 美元。

版本 1.5.0

8 月 7 日发布的 1.5.0 加快了 EPUB 打开速度，加入离线字典、从右到左与 CJK 文本渲染；首次支持 reTerminal Sticky（ESP32-S3）。

安装与管理

可通过 Web 闪刷工具或 SD 卡安装；默认固件渲染慢、导航笨拙，CrossPoint 体验更佳。设备内置 HTTP 服务器（无 HTTPS），访问 crosspoint.local 或 DHCP 分配的 IP 即可传文件、改设置；Calibre 插件可优化 EPUB（缩略图、去除内嵌字体、拆分章节）。

阅读体验与路线图

阅读体验"尚可（adequate）"，代码块无样式；支持自动翻页（最高 12 页/分）、StarDict 字典、KOReader 进度同步、Hardcover 追踪。路线图上：Phase 0 已完成；Phase 1 扩展设备、降低内存占用；Phase 2 多语言 UI 与字体。

虚拟化 / KVM

KVM planes 整装待发

作者：Jonathan Corbet 发布日期：2026年8月11日 英文原文

机密计算（confidential computing）需要在单一虚拟机内建立多个安全域。各厂商方案各不相同：Arm 的 Realm Planes、AMD 的 SEV-SNP（最多 4 个特权级）、Intel 的 TDX partitions、以及微软 Hyper-V 的 Virtual Trust Levels。

KVM planes

由 Jörg Rödel 等人开发的 KVM planes，名称取自 Arm 以统一称谓。一个 plane 封装处理器/虚拟机监控器的特权级，与所属 plane 共享地址空间但拥有自己的寄存器；新增 ioctl() KVM_CREATE_PLANE 用于创建 plane。vCPU 必须属于更特权 plane 的一个子集。

调度与实现

同一 vCPU 在同一时刻只有一个 plane 在运行；补丁集的策略是"编号最小的 plane 先运行"，Bonzini 对此提出了质疑。

实现上已支持 SEV-SNP（Coconut SVSM 运行于特权级 0，Linux 运行于 2）；Hyper-V 用 VTL1 安全内核、VTL0 客户内核，并演示了 HEKI（hypervisor-enforced kernel integrity，虚拟机监控器强制内核完整性）。

状态：相关讨论仍在演进中，尚未固化。

内核 / BPF · 验证

为 BPF 做更多形式化验证

作者：Daroc Alden 发布日期：2026年8月10日（LSFMM+BPF 2026 报道） 英文原文

在 LSFMM+BPF 2026 峰会上，Kumar Kartikeya Dwivedi 提出为 BPF 加入领域特定的不变量。BPF 验证器能保证内核不会崩溃，但 sched_ext 的看门狗每月会踢掉 1–2 个调度器（以 Meta 为例），而一个 XDP 程序若丢弃数据包则可能导致失联。

主张

Dwivedi 认为，性能性质同样属于安全属性；应当借助如 Verus（Rust 验证工具）这样的手段，对关键属性（例如"有可运行任务时 CPU 不得空转"）做静态验证。他以一个简化的 push()/pop() 接口为例演示如何证明不变量。

讨论

Alexei Starovoitov 质疑引入两条静态分析管线是否妥当；Dwivedi 回答说采用 Rust wrapper 加 Verus 注解，编译出 BPF 字节码后再走内核验证器。David Vernet（Hung）问到 wrapper 的共性；由于时间耗尽，会话未能得出结论。

发行版 / 系统安全

shadow-utils 口令过期功能的变更

作者：Alejandro Colomar（shadow-utils 维护者） 发布日期：2026年8月7日 英文原文

4.20.0 版本移除了以下内容：expiry 命令；/etc/shadow 第 4 字段（最小改密天数）被忽略并移除；groupmems、logoutd 移除；DES/MD5 哈希移除，默认改为 SHA512。

依据

上述变更基于 NIST 800-63B rev4——该标准明确禁止周期性改密（"SHALL NOT require subscribers to change passwords periodically"）；2015 年的一篇论文也证明周期性改密的收益极小。

保留但弃用

chage、passwd、useradd、usermod 的相关选项被保留但标记为弃用；第 3/5/6/7 字段因合规要求（例如西班牙的 CNI）暂予保留。

对于"无最小密龄"的情况，组织应当规划淘汰周期性改密策略。

内核 / 块层

块层错误注入

作者：Haris Iqbal 发布日期：2026年8月12日 英文原文

现有机制的缺陷

fail_make_request（2006）只能概率性报错，且状态固定为 BLK_STS_IOERR；should_fail_bio()（2018 的 BPF 钩子）能选定 bio，但状态不可选；device-mapper 的 dm-error/dm-flakey/dm-dust 需要堆叠设备且状态固定。

新机制

Christoph Hellwig 的补丁（CONFIG_BLK_ERROR_INJECTION）为每个 gendisk 建立 /sys/kernel/debug/block/<disk>/error_injection。写入形如 add,op=READ,start=1000,nr_sectors=500,status=TRANSPORT,chance=10 即可增加一条规则。

实现与争议

钩子位于 submit_bio_noacct_nocheck()，调用 blk_error_inject()，并借助静态键（static key）优化；以 RCU 遍历规则，首个匹配项设置 bi_status 并调用 bio_endio()。零长 bio（纯 flush）暂不支持。

BPF 争议：Hellwig 拒绝了 BPF_STRUCT_OPS 方案，认为那需要暴露内部 BTF、难以使用。该机制已合入 7.2，并新增 blktests/block/044 测试。

开发

Django 转向年度发布周期

Django Python Web 框架项目宣布接受年度发布周期提案，从原先"短寿特性版 + 长期支持（LTS）版"交错的复杂日程，改为更简单的年度周期，每个版本支持三年。

每个特性版都获得三年支持：一年常规 bug 修复，随后两年安全与数据丢失修复。"LTS"标签退休——每个特性版现在都承载同样、唯一的承诺。

不再有 LTS 空档：不必为了一次性跨两年的变更而赶 deadline。在支持窗口内随时按你的节奏，每年升一级。任意时刻支持三个版本，给第三方包一个清晰、滚动的目标。

该变更自即将到来的 Django 2028（预计 2028 年 1 月）起生效。

Bernard：GNOME Shell 的设计愿景

GNOME 贡献者 Tobias Bernard 发布博文，详述设计团队对 GNOME Shell 的长期构想：

其中一些我们有相对完整的计划，另一些则更模糊、需要更多研究与原型。和往常一样，这些想法能否落地取决于开发者的能力与兴趣（有时还有资金）。

虽然每个想法都可能需要进一步讨论、原型与测试，但我们（设计团队）还是把它们汇总于此，以分享更长远的愿景，并让每个想法获得更多关注。

本期（8 月 5–13 日）内核相关补丁数量庞大，以下按类别择要摘录，完整列表见 LWN Announcements 页面。

内核发布

  • Linux 7.2-rc7（Linus Torvalds，8 月 9 日）、7.1.8 / 7.1.7（8 月 9 / 6 日）、6.18.44 / 6.18.43、6.12.103 / 6.12.102、6.6.151 / 6.6.150 / 6.6.149、6.1.182 / 6.1.181、5.15.215 / 5.15.214、5.10.264 / 5.10.263，以及 5.10.262-rt158（8 月 7 日）。

架构相关

  • arm64：移除未使用的大端（big-endian）支持；s390 引入 arm64 KVM。
  • LoongArch：KVM 独立 vmid 支持、新增 KHO 支持与 selftests。
  • RISC-V：KVM PMU 事件过滤支持；bpf/riscv 为 RV64 JIT 添加 BPF 栈参数支持。
  • x86：尝试理顺 PV clocks 与 TSC 的关系；新增 RMPOPT 支持。
  • s390：vfio-ap 添加实时客户机迁移支持。

核心内核

  • kfuncs / struct_ops 添加 arena 参数支持；tracing/boot 支持 eprobe、fprobe、tprobe 事件并加测试框架。
  • kdump 缩减 vmcore 大小与捕获时间；BPF 引入全局 percpu 数据；proxy execution 的 Sleeping Owner Handling（v31）。
  • Rust 的引用计数中断禁用与 SpinLockIrq；wprobe x86 watchpoint；workqueue 的 OwnedQueue / ScopedQueue / ScopedWork。
  • BPF tracing_multi link 支持；rcu/srcu 使 call_rcu()/call_srcu() 可从任意上下文安全调用；sched proxy execution 兼容 sched_ext。
  • BPF 支持至多 16 字节的聚合返回值；steal_governor 引入 preferred CPUs 与 steal 驱动的 vCPU 回退；BPF 新增 linux_binprm 用户内存访问 kfuncs。

构建系统

  • resolve_btfids 为 kfuncs 实现 BTF tags 发射；objtool/arm64 将 klp-build 移植到 arm64；perf build 新增安装构建 perf 所需开发包的目标。

开发工具

  • Page Alloc Hogger；anon mTHP collapse 测试用例；改进 khugepaged 覆盖；xsk shared-UMEM 覆盖与基础设施；firewire core 树构建 KUnit 测试；boottime tracing 测试框架；resctrl L3 缓存与 AMD MBM/MBA 测试支持。

设备驱动（择要）

  • Rockchip 平台 Synopsys DisplayPort 控制器改进；SpacemiT K3 的 UFS 主机驱动；RK3576 NPU（RKNN）使能；Sony IMX908 / IMX708 图像传感器驱动。
  • Adreno 830 GPU 支持；nova-core GPU 中断与 GSP 事件投递；Apple SoC CIO（USB4/Thunderbolt）复位控制器；MediaTek T9XX WWAN 驱动。
  • ath12k 扩展 TX/RX 可观测性 DP 统计；bnxt_en 添加 kTLS TX 卸载；net: mana HW 通道可靠性与加固修复；nbl（Nebulamatrix）网卡驱动。

设备驱动基础设施

  • rust: leds 添加 led classdev 抽象；rust: dma 添加单缓冲流式 DMA API；of overlay 代码学会保持 /aliases 同步；virtio 支持拥有自身 virtqueue 内存的设备；rust: usb 抽象（向 Rust 移植 usbsevseg.c）；drm 添加 DRM_MODE_ATOMIC_RESET 标志。

文件系统与块层

  • f2fs 支持设备别名动态预留/释放、支持未缓存缓冲 I/O；block 设备 NVMEM provider 支持；改进离线/只读 zone 处理；buffer 写失败时停止清除 BH_Uptodate。
  • netfs 用分段 bio_vec[] 链跟踪 folios；btrfs 新增 xattrs 每 inode 压缩级别、部分同步 dirops 的 -ENOMEM 容错；nfs 现代化直接 I/O 路径；cephfs kclient 降低 mdsc->mutex 争用；erofs 为文件后端挂载共享超级块。

内存管理

  • 区分 PTE 表存储与 PTE 值；引入 package-aware 加权交错；zsmalloc shrinker 感知预算；MGLRU 用 PUD 级 Bloom filter 在老化时跳过空 PUD 子树。
  • 无条件每-VMA 锁及清理；MAP_PRIVATE 文件支撑 folios 按匿名 pgoff 索引；Virtual Swap Space（Swap Table 版）；BPF 驱动的主动 memcg 回收；kfree_nolock() 处理 kmalloc() 对象。
  • guest_memfd 就地转换支持；分层 memcg 限制；huge_memory folio 拆分清理并解除 swapcache 拆分限制；swap 休眠槽位移出 swap 缓存；移除 memcg v1 soft limit；MGLRU 修复 swappiness 行为。

网络

  • neighbour 将 arp_tbl 与 nd_tbl 命名空间化；netfilter 将 ipset 切换到 rhashtable；硬件 pacing 卸载；mptcp 乱序队列剪枝；ipv6 在 RTM_DELROUTE 中报告路由被删原因；TLS 1.3 硬件卸载；mptcp v7.3 杂项特性。

安全相关

  • audit 测量并降低 syscall 过滤开销；module_blacklist 参数扩展到内建模块；实现 LANDLOCK_RESTRICT_SELF_NO_NEW_PRIVS；PTRACE_SET_SYSCALL_INFO 添加 seccomp 跳过系统调用支持；nfsd/sunrpc 加固 netlink 监听接口。

虚拟化与容器

  • 移除对 Windows Server 2012/2012R2 与 Win8/Win8.1 版 Hyper-V 的支持；KVM x86 添加 LASS 虚拟化；KVM PPC 暴露嵌套客户机 CPU 兼容模式；KVM arm64 添加 GICv5 IRS 支持。
  • Bao 虚拟机监控器 IPC 与 I/O 分发驱动；MSHV 为根分区添加 SEV-SNP 支持；KVM ITS pKVM 加固；KVM TDX 启用 VM-DoS 防护；清理 KVM 时钟（第一部分）；KVM arm64 nv 实现嵌套 stage-2 反向映射；VBS/VSM-on-KVM 用 VM Planes 实现主机/客户机支持；Hyper-V 为 Linux 客户机添加半虚拟化 IOMMU。

杂项

  • perf sched latency 细化输出、单位缩放与直方图支持；perf c2c 添加函数视图；PERF_SAMPLE_BUILD_ID_OFFSET；perf arm64 支持数据类型剖析；rust 添加 ID 区间预留支持与 #[macro_export_scoped]；coredump 允许在 coredump socket 上创建稀疏核心转储。
